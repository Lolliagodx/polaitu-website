# Полайту — сайт

Исходники сайта «Полайту» из предоставленного архива.
Статические HTML, CSS и JavaScript; сборка и база данных не требуются.

Предпросмотр: https://Lolliagodx.github.io/polaitu-website/

## Локальный запуск

```sh
python -m http.server 8000
```

Откройте http://localhost:8000.

## Обновления

Изменения сохраняются в ветке main. GitHub Pages публикует предпросмотр.
На основной хостинг итоговая версия переносится по команде владельца.

## Внешние сервисы

Изображения и видео подключены с исходного CDN. Формы используют Formspree,
аналитика — Яндекс Метрику. Доступность этих сервисов зависит от их владельцев.
Данные доступа к хостингу и другим сервисам в репозитории не хранятся.
